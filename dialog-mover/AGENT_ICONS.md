# 原版软件图标

左侧软件列表、搬运目标及 ChatGPT / Claude 的模式选择共用一份图标映射，不再使用字母缩写代替品牌图标。

`ui/assets/agents/sources.json` 记录每份图标来源、尺寸与 SHA-256。图标来自本机安装的软件资源、已安装的 Grok 网页应用，以及 txcript 上游的 Grok Bot 资源；没有使用 AI 重画或改色。WorkBuddy 国内和海外版当前安装包使用相同图标，以文字标签区分。千问办公、豆包工作使用办公产品自身图标，而非同品牌聊天产品的图标。

Hermes 原版图标尚未成功取得，明确使用通用软件图标，不伪造品牌标记。图片丢失或未识别的软件也会显示通用图标并提示，不阻断工具功能。

GitHub Copilot 使用其已安装桌面 App 程序资源内的原版图标，透明 PNG 随软件打包，来源和摘要同样记录在清单中。

ChatGPT 在浅色界面使用本机安装包提供的 `altform-lightunplated` 黑色透明标志，不使用白色标志搭配人为添加的黑色底板。来源列表、搬入菜单以及本机 Work／Codex 的模式选择共用同一资源；PNG 原文件直接复制，不重画或改色。

图标渲染只读取随软件打包的图片，不访问网站，也不要求原软件仍然安装。`ui/assets/agents/sources.json` 用于记录资源来源，不属于运行依赖。软件的会话读取能力与图标渲染是不同功能。品牌图标属于各自权利人；仅用于识别软件，不表示官方合作关系。

验证：`python -m unittest test_agent_icons test_import_ui -v`。图标测试用合成记录，不执行真实搬运。
