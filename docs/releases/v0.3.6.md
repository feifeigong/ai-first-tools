# AI一手工具箱 v0.3.6 · Windows 预览版

## 普通用户点这里

**[下载安装包](https://github.com/feifeigong/ai-first-tools/releases/download/v0.3.6/AI-First-Tools-Setup-0.3.6.exe)** → 双击安装 → 以后从桌面打开。

已有旧版：先关闭工具箱，再安装新版。不需要卸载，不需要下载源代码，也不用安装 Python 或 .NET SDK。

需要免安装版？下载 **AI-First-Tools-Portable-0.3.6-win-x64.zip**，解压整个文件夹后打开「AI一手工具工作台.exe」，不要只复制 EXE。

## 这次更新

- 对话搬家的外层工具菜单和内页标识统一为同一张黑底双色双箭头图标。
- 保留图标原始颜色、透明圆角和比例，不再给内页图标额外套不同颜色的底框。
- 更新示例界面截图；截图仅包含合成记录。
- 增加图标一致性回归与发布包检查，避免以后打包又带入旧图标。

搬家功能、支持范围和迁移引擎与 v0.3.5 相同，未借此更新修改用户的对话数据。

## 使用前请注意

支持 Windows 10 / 11 x64。首次使用若缺少微软 WebView2，安装程序会联网准备。

这仍是预览版，不是所有来源到所有目标的原生续聊保证，也不是 Windows 全新虚拟机认证。重要记录请先备份，搬完后到目标软件检查。附件、模型配置、权限和项目文件不会一起迁移。详见 [支持范围](https://github.com/feifeigong/ai-first-tools/blob/master/docs/SUPPORT.md)。

安装包尚未购买代码签名证书，Windows 可能提示「未知发布者」。请核对本仓库及 SHA256SUMS.txt，不需要关闭系统安全防护。
