# AI一手工具箱 v0.3.21

自动用卡现在必须确认周额度使用率达到100%，99%或99.9%不会提前尝试。用卡前会再次读取额度，有剩余额度、无可用卡或收到停止请求时跳过。

自动续跑开启时，5小时额度单独用完仍等待恢复；关闭时不自动续跑、不自动使用重置卡，并取消开机自启。已有开关和配置保留，Tibo提醒仍独立运行。

新增边界和停止保护的合成回归，并要求Windows冻结运行包和Mac原生包实际通过严格用卡门槛检查。检查不读取真实账号额度，不使用真实卡，不发送模型请求。详情见[续跑规则](https://github.com/feifeigong/ai-first-tools/blob/master/docs/AUTO-RESUME-CONTROL.md)。
