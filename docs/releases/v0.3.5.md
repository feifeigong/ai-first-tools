# AI一手工具工作台 v0.3.5 · Windows 预览版

## 普通用户点这里

**[下载安装包](https://github.com/feifeigong/ai-first-tools/releases/download/v0.3.5/AI-First-Tools-Setup-0.3.5.exe)** → 双击安装 → 从桌面打开。

不需要拉取源代码、运行命令、安装 Python 或 .NET SDK。支持 Windows 10 / 11 x64；第一次缺少 WebView2 时安装程序会联网准备。

需要免安装版本？下载 **AI-First-Tools-Portable-0.3.5-win-x64.zip**，解压整个文件夹后打开「AI一手工具工作台.exe」，不要只复制 EXE。

## 这次发布

- 首次公开 AI一手工作台、对话搬家和修改后的 txcript 完整源代码。
- 新增当前用户安装包、桌面入口、开始菜单入口及 Windows 卸载入口。
- 工作台自带 .NET，迁移引擎附带所需运行库，减少新电脑上的准备步骤。
- 安装/卸载拒绝在工作台运行期间操作，不强制结束搬运任务。
- 卸载只移除登记的程序文件，保留用户额外文件、用户配置和各 AI 软件的对话。
- 保留现有界面、品牌 Logo 和迁移逻辑，不借此次发布改写用户已验证的引擎。

## 验证与限制

发布前 58 项 Python 回归、34 项工作台自检、21 项原生窗口检查通过；安装、运行环境自检、更新保护、错误路径拒绝和卸载保留文件检查通过。

这不是所有来源到所有目标的原生续聊保证，也不是 Windows 全新虚拟机认证。普通云端 ChatGPT / Claude、豆包工作、Hermes 不提供原生搬入。附件、权限、模型配置和项目文件不会迁移。详见 [支持范围](https://github.com/feifeigong/ai-first-tools/blob/master/docs/SUPPORT.md)。

安装包尚未购买代码签名证书，Windows 可能提示「未知发布者」。请核对本仓库及 SHA256SUMS.txt，不需要关闭系统安全防护。

这是预览版，重要记录请先备份。欢迎通过 [Issues](https://github.com/feifeigong/ai-first-tools/issues) 反馈；请不要公开登录文件、聊天正文或个人路径。
