# AI一手工具箱 0.4.5

Windows 与 Mac 同步支持把对话复制到 DeepSeek 官方桌面端和 DSH 社区版。

- 可以从 ZCode 复制看得到的对话，也可以从 Codex 或 ChatGPT 本机工作记录复制。原记录保留，工具过程和附件不会重放。
- 官方 DeepSeek Harness 与社区 DSH Desktop 分开存放，两边都可以作为来源和目的地。读不了对话的软件不再出现在列表里。
- Windows 上如果对应窗口已经打开，搬完后会重新打开并显示新记录。Mac 使用同一套复制代码，打开对应软件后可以查看。

## 更新与安装

Windows 提供安装包和免安装 ZIP；Mac 提供 Apple 芯片和 Intel 芯片两个 DMG。使用工具箱内「检查更新」，或本页对应平台的完整安装包，完成后重新打开工具箱。

Mac 版本标识为 `0.4.5-macos-preview.33`，仍为未签名、未公证的预览版。Windows 与 Mac 共用同一套搬家代码；两端构建与验收通过、下载文件再次核对后才公开。

## 本版验证范围

搬家检查使用隔离合成记录，不读取用户真实会话、认证或数据库，不发送模型请求。写入后能重新读出正文，不等于目标软件里的附件、工具调用和下一轮对话都已验收。Mac 的窗口自动重开不在本版范围内。
