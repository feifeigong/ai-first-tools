# AI一手工具箱 v0.3.22

自动续跑与自动用卡分开控制。可以开启续跑、关闭用卡，等待自然恢复或官方重置实际到账后继续任务。周额度自动用卡仍要求确认达到100%；5小时限额单独用完不触发用卡。提醒弹窗的操作也改为只关闭用卡。

新增默认关闭的“自动开启5小时计时”。在适用的账号额度窗口和轻量模型可用时，按需发送一次极短的临时会话请求；正常任务优先，不进入工作聊天，不调用重置卡。会消耗少量套餐额度，必须拿到官方新的恢复时间才显示计时成功；未知或超时结果不会重复补发。

续跑与计时独立控制，登录后运行会恢复已开启的功能。关闭续跑后不继续任务或自动用卡；计时若单独开启，仍会发送那一次轻量请求。既有设置保留，新计时不会自动开启。

开发和CI使用隔离合成数据、原生界面及冻结运行包检查，不读取真实聊天或认证，不实发模型消息或消耗重置卡；不把合成检查冒充真实账号计时已经生效。详见[功能与适用范围](https://github.com/feifeigong/ai-first-tools/blob/master/docs/FIVE-HOUR-TIMER.md)。
