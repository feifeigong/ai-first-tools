# AI一手工具箱 0.4.4

Windows 与 Mac 同步修复自动续跑误启动子任务的问题。

- 额度恢复后，只自动继续能确认身份的主任务，跳过子代理、审批守护任务和身份不明的记录。
- 提交前再次检查：已经恢复、结束或日志无法完整核对的任务不自动启动；同一线程的旧限额记录不会覆盖新的进展。
- Windows 更新时接管能确认归属的旧独立监控，保留自启选择；停止失败时不启动第二个后台，也不停止已有 Codex 子进程。

## 更新与安装

Windows 提供安装包、免安装 ZIP；Mac 提供 Apple 芯片和 Intel 芯片两个 DMG。使用工具箱内「检查更新」或本页对应平台的完整安装包，完成后重新打开工具箱。

Mac 版本标识为 `0.4.4-macos-preview.32`，仍为未签名、未公证的预览版。Windows 与 Mac 共用相同的会话识别代码；两端全部构建与验收通过、下载资产再次核对后才公开。

身份不明、首条元数据损坏或无法完整读取日志时，自动续跑会跳过；文件恢复可读后会在后续检查重试。带分叉、回退或复制历史且无法区分本任务限额的记录也会跳过，可以回到 Codex 手动继续。保留多个工具箱安装目录时，请关闭旧版本后再使用新版。

## 本版验证范围

新增回归覆盖多个子代理同时等待、主任务恢复、身份缺失或冲突、同线程多日志、读取失败，以及提交前继续活动。Windows 和两种 Mac 芯片的冻结包均必须通过主任务识别与提交前复核检查，才能进入发布。

会话与额度测试均使用隔离合成数据和假客户端，不读取用户真实会话、认证或数据库，不发送模型任务，不消耗订阅额度或重置卡。原生组件的版本、参数和未登录历史兼容检查不代表真实账号续跑验收。
