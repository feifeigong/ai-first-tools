- 智能搬家保存完整旧对话、本地索引和只读检索资料，Copilot 使用独立资料项目；已有工作项目保留。

## 包的用途与未完成项

Windows ZIP 是独立便携预览。解压后运行目录内的工作台，不需要覆盖正式安装；预览保留独立设置并禁用正式自动更新。

Mac ZIP 是接续开发用的源码和报告，入口为包内的“先看这里.txt”和 `docs/MACOS-HANDOFF.md`。它没有替代 Mac 本机的 Cocoa、通知、登录自启、目标软件列表和两种芯片验收。

Mac 搬入 Copilot 后的自动列表刷新仍有明确缺口，整体功能对等尚未验收。真实模型后续多轮对话、长期消息覆盖以及节省额度效果也未由离线回读证明；不得据此声称所有客户端均已实测通过。

当前 GitHub 自动流程只运行无需模型请求的测试。开发草稿及自动构建成功均不等于正式发布授权，不覆盖已有公开资产。
