# v0.3.7 更新功能验收

日期：2026-10-12。测试环境：现有 Windows x64 电脑，不是干净虚拟机。

## 已验证

- 工作台自检 62 项通过，包含 28 项新增更新检查：版本数字排序、公开预览版、草稿与残缺资产过滤、固定来源、HTTPS 跳转、大小与双层 SHA-256 校验、取消、错误响应、ZIP 路径与链接检查、清单验证、文件替换、额外文件保护和故障回滚。
- 原生窗口检查 21 项通过，包含任务未完成时拒绝关闭、保留进程和窗口、完成后正常关闭而非强杀。更新流程复用这条安全关闭逻辑。
- 对话搬家回归 59 项通过。此次没有改写搬家 EXE 或迁移引擎，二者哈希与 v0.3.6 相同。
- 隔离的 v0.3.7 → v0.3.8 交接测试通过：模拟本项目 Release 与本地下载，验证 ZIP 后退出旧进程，独立更新进程替换文件，新版自动打开并显示「已更新到 v0.3.8」。新工具测试窗口正常打开，额外用户文件内容保持不变。
- 原生 UI 已观察到「有新版本」「更新并重启」及更新完成状态。手动点击测试被并行用户输入阻止，交接回路使用隔离程序化测试完成，未冒称人工点击全流程。
- v0.3.7 安装包的运行保护返回 1603，原有正在运行的 v0.3.6 EXE 哈希未变化。
- 发布包清单、全部文件哈希、运行库、品牌资源、第三方许可证及私有数据排除检查通过。

## 验证边界

- GitHub 公开版本仍是 v0.3.6；没有为测试发布假版本。此次完整升级回路是隔离免安装包测试，不是公网下载新 Release 的验收。
- 安装版静默覆盖与自动重启已经实现，但未在干净 Windows 环境跑完 v0.3.7 → 新版的完整正向安装升级；没有为此覆盖用户正在使用的程序目录。正式公开下一版之前应补做该项。

- 本次更新功能测试不扩大各目标 Agent 的原生显示、继续对话与附件迁移支持范围。
