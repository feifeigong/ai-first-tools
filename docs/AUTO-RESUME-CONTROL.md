# Codex 自动续跑控制页

Windows 工作台增加内置的「Codex 自动续跑」入口。它连接本机已安装的 Codex Auto Resume，不重做额度判断、会话发现或续跑逻辑。未安装原工具时显示说明并禁用开关，不安装 Python、不请求模型。

- 自动续跑开关：开启已有后台程序；关闭时先禁用计划任务和启动文件，停止对应的 VBS 守护，再按完整命令确认并停止 watcher。关闭同时取消开机自启，防止被再次拉起。
- 开机自动开启：单独控制下次登录的启动入口，不启动或停止当前 watcher；优先复用原计划任务，无任务注册权限时沿用启动文件方式。原任务不允许普通用户修改时，使用原工具入口的 `allow_background_watch` 检查：读取本机开机偏好，关闭时直接正常退出，不启动续跑逻辑、不更改任务权限。
- 退出工作台只关闭控制页，不发送停止 watcher 的指令。设置变更进行中会等待结果再退出。
- 页面打开时读取实际状态，可手动刷新，可见时每 30 秒更新。状态读取失败时不显示缓存为当前状态，禁用操作并保留刷新入口。

路径从原计划任务、真实 watcher 命令、启动文件或本机连接记录发现，源码不包含用户安装路径。连接记录仅保存 Python 和原工具入口位置；开机偏好单独保存为 `auto-resume-startup.json`。不读取认证、聊天、数据库或原配置。停止前重新核对命令，不读 PID 文件、不结束整个进程树、不关闭 Codex。工作台显式开启时仅对子进程设置 `AI_FIRST_MANUAL_WATCH=1`，因此开机自启关闭时仍能手动开启当前运行。

已存在但无法确认属于原工具的同名计划任务会拒绝修改。读取状态不写入设置；点击开关后才保存连接记录。该页只控制当前 Windows 本机安装，未增加 Mac 入口或在线发布。
