# Mac 版：下载安装与使用

Mac 预览版通过 GitHub 发布，不上苹果商店，不使用 Developer ID 签名或苹果公证。

## 下载与安装

[Mac 发布页](https://github.com/feifeigong/ai-first-tools/releases/tag/v0.4.0-macos-preview.3)

1. 苹果 M 系列选 `macos-arm64.dmg`；Intel Mac 选 `macos-x86_64.dmg`。苹果菜单 → 关于本机可以查看芯片类型。
2. 打开 DMG，把「AI一手工具工作台」拖到「Applications / 应用程序」。
3. 在应用程序中打开工作台，点「对话搬家」使用。可以保留在 Dock。

不需要源码、终端、Python、Rust、.NET 或 WebView2。不要下载 Windows EXE 或 Source code。

以 macOS 13 及以上为兼容目标，首批实际打包和窗口检查在 macOS 15；较早系统尚待验收。系统提示不兼容时请记录版本，不强行运行。

## 未签名的首次打开提示

作者选择不签名、不公证，首次打开可能被拦截，不能保证和已签名应用一样顺畅；软件未经过苹果公证或审核。

仅在确认来自本项目并核对发布校验值后，按 [苹果官方流程](https://support.apple.com/zh-cn/102445) 处理：先尝试打开，再到「系统设置 → 隐私与安全性」查看是否有针对该应用的「仍要打开」。不同系统版本、公司管理的电脑可能不同。

提示恶意软件、损坏或没有允许打开选项时，请停止并反馈。不要关闭 Gatekeeper/杀毒软件，不执行不明来源的解锁命令。

## 更新与卸载

- 启动后后台检查 GitHub，也可点「检查更新」；只查询公开版本，不上传对话、认证或本机路径。
- preview.2 使用 Mac 系统证书与系统代理，不要求电脑另外安装 Python 的证书。连接失败会区分超时、证书、地址解析或限流，并提供「打开下载页」，不把失败说成已经最新。
- preview.3 起，有新版会自动出现「下载并更新」。点一次即可在软件里下载、校验，等待搬运结束后自动更新并重新打开，不需要再拖拽或重新安装。持续打开时每六小时后台再检查一次，也能手动检查。
- 下载时可以继续使用或取消。应用只接受本项目、当前芯片且校验文件完整的更新；验证失败保留当前版本，替换失败尝试恢复，旧版备份保留，不删除 Agent 数据。
- **preview.1/2 没有一键覆盖功能，需最后一次手动替换到 preview.3；之后使用软件内按钮。** Windows v0.3.7 起已经支持一键下载更新，v0.3.8 统一按钮名称。
- 请从「应用程序」或自己可写的正常安装目录打开。在 DMG、系统隔离运行位置、不可写目录或不支持安全交换的磁盘中，不强行更新，会提示先处理安装位置/权限。系统安全策略可能仍要求用户确认，不关闭系统保护。
- 卸载只把工作台移到废纸篓，不需要删除其他 AI 软件的记录。

## 能力与边界

Mac 用一个 Cocoa/WebKit 窗口直接显示工作台和工具，不启动另一个窗口再合并。共用原有来源读取、目标模式、搬运、去重、关闭保护和实际 Agent Logo。

- 适配 Application Support、POSIX 路径、原生引擎、打开文件夹和本机任务链接。
- 目标按本机数据与原生结构检查，不因移植伪造支持。ChatGPT 本机 Work/Codex 与云端分开，Claude Cowork/Claude Code 与普通聊天分开。
- 豆包、Hermes、普通云端聊天不作为可写目标；OpenCode 需要另有原生 CLI，不偷偷安装。
- 豆包工作从 Mac 的 `~/Library/Application Support/DoubaoWork/Default/` 读取会话列表和本机轨迹，修复首版误用 Windows 的 `User Data/Default/`。只有本机存在的任务能搬出；纯云端对话仍不可搬运。打开来源软件后可以点右上角刷新，重新寻找来源，无需重启工作台。
- 不迁移项目文件、附件、登录状态、模型权限和运行环境。
- **回读通过不等于所有原生软件实际显示和下一轮对话通过。** 见 [测试记录](MACOS-QA.md)。

反馈提供软件版本、Mac 系统/芯片、来源/目标版本、步骤和脱敏截图。不要上传聊天、完整个人路径、数据库或令牌。

如果旧版「检查更新」无法连接，请直接到上面的发布页完成这一次升级。新版仍提示连接失败时，反馈完整提示文字即可；浏览器也无法打开 GitHub 时，需要先检查本机网络，应用不能保证绕过网络限制。更新机制和验证边界见 [Mac 软件内更新](MACOS-UPDATES.md)。
