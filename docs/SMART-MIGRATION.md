# 智能搬家使用说明

把长对话带到 Copilot，保留完整旧记录，聊天时只查需要的部分。当前 Windows v0.3.20 和 Mac preview.23 均已包含此功能；下载入口见 [首页](../README.md#下载安装)。

## 和完整搬家有什么区别

| 对比项 | 智能搬家 | 完整对话迁移 |
| --- | --- | --- |
| 旧记录保存在哪里 | 完整记录保存在工具箱的本机资料区，Copilot 按需检索。 | 旧消息复制到目标软件的历史中。 |
| 在目标软件里看到什么 | 独立资料项目及「原名称（智能搬家）」对话，开头是一段简短说明。 | 搬入的旧消息，具体显示取决于目标软件。 |
| 适合什么情况 | 旧对话很长，想接着做事，减少反复携带大量历史。 | 想在另一个软件的历史里直接查看旧消息。 |
| 当前目的地 | GitHub Copilot 独立桌面端。 | 工具中开放搬入的软件和模式。 |

“省额度”是按需检索的使用思路，不是固定节省比例的承诺。准备搬家不调用模型；之后与 Copilot 聊天仍按正常用量计算。

## 怎么操作

1. 先安装并打开 Copilot 桌面端，完成它自己的初始化和登录。
2. 打开工具箱的「对话搬家」，选择来源软件，勾选想继续的对话。
3. 点击「搬到…」，选择 **「智能省额度迁移」**，再选 **「Copilot 桌面端」**。
4. 核对将要使用的对话名称，点击 **「开始搬家」**。
5. 到 Copilot 中输入并发送下一步要求，例如「看看上次做到哪里了，再继续」。

智能流程不用选工作目录、合并配置或逐条确认旧要求。旧记录中需要以后继续遵守的内容，可以在搬完后按需处理，不是搬家的必填步骤。

## 搬好后在哪里找

初次搬入会在 Copilot 新增工具箱专用的独立资料项目，每条对话沿用原名称并加上 **「（智能搬家）」**。多选的记录分别保存，同名但来自不同记录的对话也分别保留。

完成后工具会请求打开对应对话。看到简短搬家说明是正常的：完整旧记录供 Copilot 按需查找，**输入并发送新要求后才会产生回复**，搬家过程不会自动发送提示词。

回到工具箱，原记录旁的「已智能搬家」可以请求打开对应对话；「···」里可查保存的原文、更新长期要求、改用完整迁移或撤销。这些都不是继续聊天前必须做的操作。

关闭工具箱窗口后，不必为了检索旧记录一直开着窗口；请保留工具箱的安装和本机资料，Copilot 查旧记录需要这些组件与文件。目前不提供跨电脑自动同步。

## 重复搬家会不会越来越多

同一来源、同一记录再次智能搬家，会复用已经核实的资料项目和对话，保留你之后的聊天与改名。来源新增的消息会更新工具箱保存的原档和索引。

如果原入口已被归档、关联异常，或保存信息无法核实，工具会保留现有内容并提示问题，不会盲目新建同名副本。早期版本已经产生的重复项也不会被自动合并或删除。

## 会影响原来的项目吗

来源记录只读，搬家只做复制。Copilot 会新增本次所需的资料项目、对话及登记；**不会往已有工作项目放入资料或合并它的设置，也不改变 Copilot 的数据库结构、登录和模型选择。**

这不表示目的软件完全没有新增文件：新对话需要保存，智能资料项目也有自己的设置。保护范围是搬家操作；你以后主动让 Copilot 在项目里做什么，仍由你的新要求和 Copilot 自身权限决定。

项目文件、外部附件、原开发环境和工具权限不会自动一起搬齐。完整原档中的附件引用会保留，不能把它当作附件文件的完整备份。

## 没有自动显示怎么办

如果 Copilot 正在执行任务或有未发送内容，工具会先保留它们，等待合适时机；遇到打开错误，可按结果页提示重试，重试打开不会再搬一份。

Windows 已验证受保护的列表刷新。Mac 包含同一搬家业务及原生保护检查，但 **已登录 Copilot 的实际刷新菜单、侧栏显示和切换找回仍待真机接续验证**；不能承诺所有 Mac 客户端都能自动刷新。若提示无法同步，请先保存草稿、完成任务，再正常重开 Copilot 查看。

当前不是 GitHub 官方的跨软件历史导入接口，而是已知本机格式适配；遇到未知结构会停止。生成记录、回读和合成检查通过，不等于每个客户端、账号和模型的后续对话都已验收，也不保证实际节省额度。
