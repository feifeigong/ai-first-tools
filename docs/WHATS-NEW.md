# 更新后的「本次更新」提示

Windows v0.3.19 / Mac preview.22 新增简短的更新说明弹窗。每个版本第一次正常打开时，会展示最多三条本次变化；点击「知道了」、关闭按钮或按 Esc 后，同版不再自动弹出。以后想再看，点右上角版本号即可。

说明随安装包一起提供，断网也能阅读。弹窗不会运行介绍里的功能、替你修改续跑或提醒开关，也不发送模型请求。自动提示只在启动时尝试一次；如果你已经开始点击或输入，或窗口没有焦点，就不再延后打断，仍可点版本号查看。「完整更新说明」会在浏览器打开本版本的 GitHub 发布页。

弹窗采用 Windows 自己的窗口和 Mac 页面原生对话框，两端共用同一份简短中文。关闭状态只记录已看过的版本，不读取聊天、认证或目的 Agent 数据。设置文件异常时不覆盖原文件，自动提示跳过，正常工作照常继续。

## 发布时怎么维护

修改 `workspace/assets/whats-new.json` 的两端版本和本次条目，同时更新程序版本及 GitHub 发布说明。每条写用户感知到的具体变化，最多三条；较长的技术记录放 GitHub 或 QA 文档。文案只作为普通文本显示，不执行 HTML、脚本或命令。

Windows 自检要求内置文案与程序版本匹配，打包还检查实际窗口的布局、焦点和三种关闭方式。Mac 将同一份 JSON 复制到运行包，原生检查要求资源、页面弹窗和已读状态均通过；缺报告的候选不发布。原有数据位置、更新校验、后台交接与搬家保护保持。
