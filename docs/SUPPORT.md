# 支持范围与验证边界

v0.3.6 是 Windows x64 预览版，不是所有软件和所有版本的全面兼容承诺。

| 目的地 | 状态与限制 |
| --- | --- |
| Cursor 桌面版 | 写入本机对话与工作区登记 |
| WorkBuddy / WorkBuddy AI | 国内与海外存储分别适配 |
| 千问办公 | 写入正文和本机项目、聊天、消息登记；依赖原生存储格式 |
| ChatGPT 本机 Work / Codex | 写入本机历史，分别标记模式并登记所选目录；不写入云端 Chat / Work |
| Claude Code | 本机项目 JSONL 历史，不等于 Claude 普通聊天 |
| Cowork | 要求先在原软件创建本机任务完成账户初始化；不写云端 |
| Antigravity 桌面端 | 本机存储适配；原软件自动重新索引、实际续聊未全面验证 |
| Antigravity CLI / Cursor CLI / Grok CLI | 写入对应本机历史，按结果页说明打开或恢复 |
| OpenCode | 调用本机 OpenCode 官方导入入口，需已安装该软件 |
| 豆包工作 | 只读来源；本机轨迹文件不等于服务器正式会话，界面不开放搬入 |
| GitHub Copilot Desktop | 本机事件历史只读搬出，未确认来源的共用记录明确标注；VS Code 自身存储与搬入 Copilot 暂不支持，见 [Copilot 说明](COPILOT.md) |
| ChatGPT 云端 / Claude 普通聊天 / Hermes | 只读来源，不提供未实现的原生写回 |

迁移记录不迁移附件、项目文件、工作环境、插件、认证、权限或模型配置。不同软件的消息、工具和多模态结构可能不同，导入提示须仔细阅读。

## 什么已经测过，什么没有

开发期间完成了隔离目录中的适配器写入/回读、标题和目录检查、失败回滚、去重以及界面交互回归。工具箱启动、内嵌工具、单窗口关闭与基础导航也有自动和人工检查。

本机 Work / Codex 有原生历史列表、读取和恢复的专项验证；恢复历史没有向模型发送下一条消息。用户也手动验证过部分搬运场景。

**上述检查不表示所有来源到所有目标在原软件里都能显示并继续对话。** 没有逐一覆盖每个原生客户端的所有版本、账户状态、付费权限、附件和工具调用；没有为验证续聊而自动发送付费模型请求。

遇到记录没显示时，先检查目标模式、文件夹、原软件筛选/归档状态和结果页说明。不要反复导入造成重复；记录问题后再排查。
