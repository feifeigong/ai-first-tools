# 支持范围与验证边界

当前公开版本为 [Windows v0.3.19](https://github.com/feifeigong/ai-first-tools/releases/tag/v0.3.19) 与 [Mac preview.22](https://github.com/feifeigong/ai-first-tools/releases/tag/v0.4.0-macos-preview.22)。下面列出已实现的范围，不表示所有软件版本与账号场景都已完成原生验收。

## 两种搬家方式

| 方式 | 当前范围 |
| --- | --- |
| 完整对话迁移 | 把旧消息复制到下表中支持搬入的本机目标。 |
| 智能省额度迁移（智能搬家） | 当前仅以 GitHub Copilot 独立桌面端为目的地；完整旧记录保存在工具箱本机资料区，在独立资料项目中按需查找。Windows/Mac 共用业务，已登录 Mac Copilot 的实际菜单与侧栏仍待接续核对。 |

[智能搬家使用说明](SMART-MIGRATION.md)包含操作步骤、重复搬家与已有项目保护范围。智能功能不支持把 VS Code、Copilot CLI、Cursor、ChatGPT 或 Claude 作为目的地。

## 完整对话迁移的支持范围

| 软件或模式 | 状态与限制 |
| --- | --- |
| Cursor 桌面版 | 写入本机对话与工作区登记 |
| WorkBuddy / WorkBuddy AI | 国内与海外存储分别适配 |
| 千问办公 | 写入正文和本机项目、聊天、消息登记；依赖原生存储格式 |
| ChatGPT 本机 Work / Codex | 写入本机历史，分别标记模式并登记所选目录；不写入云端 Chat / Work |
| Claude Code | 本机项目 JSONL 历史，不等于 Claude 普通聊天 |
| Cowork | 要求先在原软件创建本机任务完成账户初始化；不写云端 |
| Antigravity 桌面端 | 本机存储适配；原软件自动重新索引、实际续聊未全面验证 |
| Antigravity CLI / Cursor CLI / Grok CLI | 写入对应本机历史，按结果页说明打开或恢复 |
| OpenCode | 调用本机 OpenCode 官方导入入口，需已安装该软件 |
| 豆包工作 | 只读来源；本机轨迹文件不等于服务器正式会话，界面不开放搬入 |
| GitHub Copilot Desktop | 支持本机历史搬出和搬入 Desktop Chats；只列桌面端正式登记的记录，VS Code 自身聊天存储不在范围，见 [Copilot 说明](COPILOT.md) |
| ChatGPT 云端 / Claude 普通聊天 / Hermes | 只读来源，不提供未实现的原生写回 |

迁移记录不自动搬齐外部附件文件、项目文件、工作环境、插件、认证、权限或模型配置。已内嵌在消息中的图片按目标适配能力处理，不等于所有附件都已迁移。不同软件的消息、工具和多模态结构可能不同，导入提示须仔细阅读。

ChatGPT 本机项目支持已核实的普通与压缩历史，按当前项目归属分组；仅在终端使用、未被桌面项目收录的 Codex CLI 记录单独列出。只有索引、格式未知或无法完整读取的记录不会被当作已完整搬出，见 [来源验证](CODEX-SOURCE-QA.md)。

## 续跑与重置提醒

两平台安装包都内置自动续跑与独立重置提醒。5 小时额度用完后等待恢复；周额度用完时按既有规则使用可用重置卡。关闭「自动续跑」会停止本工具的自动续跑与用卡，并取消其开机自启；「提醒」开关独立，消息本身不会自动改变续跑选择。

重置监控读取 Tibo 的公开消息，中文展示预告、完成公告、重置卡、北京时间和历史日历。提醒可在关闭工具箱窗口后继续；网络、公开来源与轮询间隔会影响及时性，不保证实时或零遗漏，也不以预告时间经过来证明个人额度已到账。

## 什么已经测过，什么没有

开发期间完成了隔离目录中的适配器写入/回读、标题和目录检查、失败回滚、去重以及界面交互回归。工具箱启动、内嵌工具、单窗口关闭与基础导航也有自动和人工检查。

本机 Work / Codex 有原生历史列表、读取和恢复的专项验证；恢复历史没有向模型发送下一条消息。用户也手动验证过部分搬运场景。

**上述检查不表示所有来源到所有目标在原软件里都能显示并继续对话。** 没有逐一覆盖每个原生客户端的所有版本、账户状态、付费权限、附件和工具调用；没有为验证续聊而自动发送付费模型请求。

遇到记录没显示时，先检查目标模式、文件夹、原软件筛选/归档状态和结果页说明。不要反复导入造成重复；记录问题后再排查。
