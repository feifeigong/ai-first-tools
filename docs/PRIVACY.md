# 隐私与数据安全

- 工具箱没有自己的聊天上传服务。搬运目标是用户选择的本机软件存储。
- 智能搬家把完整原档和检索索引保存在工具箱的本机资料区，为 Copilot 新增独立资料项目，不往已有工作项目放资料或合并设置。查询服务只读指定的搬家资料，不提供任意路径读取或执行工具。准备搬家不调用模型；之后在 Copilot 中发起的聊天会按需使用检索片段，本地保存不等于后续聊天完全离线。
- Windows/Mac 内置自动续跑在用户开启后，使用本机已有 Codex 登录和会话连接 OpenAI，查询额度并在符合原续跑规则时继续原对话。不会把认证、聊天或本机路径上传至工具箱自己的服务器。后台组件随包提供，原生运行组件固定来源并在构建时校验；运行配置和任务状态保存在用户数据目录。关闭工具箱与关闭后台开关是不同操作，卸载会停止自己的后台和开机入口，但保留用户设置及 Codex 会话。
- 重置监控访问公开消息来源及 X 公开原帖核实接口，不需要读取你的 X 登录、Cookie 或私信。保存的是公开帖子与本机提醒状态；提醒不发送模型请求、不自动使用重置卡。
- 两平台会后台查询本项目公开 GitHub Release，也能手动检查；检查有节流及失败重试。不发送对话、认证、账户文件或本机路径；只有点击「下载并更新」才下载、校验和替换程序，不悄悄安装。早期不支持软件内更新的版本需手动替换一次，见首页说明。
- Mac preview.4 起不在窗口启动时异步清空工具箱自己的 WebKit 数据存储，避免重启期间与页面加载竞争。系统可能保留工具箱页面的缓存/Cookie；它只承载本机工具页面，不是 ChatGPT/Claude/豆包的登录客户端，也不会复制或上传这些软件的认证。页面仍使用随机本机端口，更新 HTTPS 的证书与域名检查不变。
- Mac preview.6 的失败恢复仅向同一个固定 GitHub 发布接口退避重试，不记录/上传网络异常原文、代理地址或认证。普通错误按 1/5/15/60 分钟退避，持续失败每小时一次；限流直接等待一小时。网络检查成功不自动下载或安装，仍需用户点击更新按钮。
- 读取 ChatGPT/Claude 等软件的本机缓存及其已有登录状态时，部分列表或正文可能需要访问**对应厂商**的服务；不是所有读取都能离线完成。
- 不要把账户文件、Cookie、令牌、数据库、完整对话、日志或诊断报告提交到公开仓库。
- 本机日志和界面中的路径可能含用户名、项目名或聊天标题。反馈前请遮盖敏感信息。
- 导入只复制记录，不删除来源；部分目标会在写入前备份或使用事务。请自行备份重要数据，不能把预览软件当作唯一备份。
- 安装、更新和卸载不应删除各 Agent 的历史目录；卸载仅移除安装程序登记的程序文件和快捷方式，保留用户配置及用户额外放入的文件。
- 本仓库与发布包不包含作者的真实聊天、数据库、登录状态、测试导入记录或私人截图。
