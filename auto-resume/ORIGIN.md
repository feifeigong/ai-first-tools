# 内置自动续跑后台

本目录将同一作者原有的自动续跑逻辑纳入工具箱统一构建和交付。基线为 `feifeigong/codex-auto-resume` 的提交 `b02c08b063c583ac0610c520192fc344509e334b`；冻结入口、包内运行组件定位、后台停止与生命周期为工具箱适配。

用户只安装 AI一手工具箱，通过同一个控制页使用。本目录不是独立安装产品。Python 运行组件由 PyInstaller 随包提供，Codex 原生运行组件按锁定清单校验后打包，不要求用户安装 Python、Node 或 Codex CLI。

`bin/` 仅存放构建时从 OpenAI 官方 npm 发布包校验取得的运行组件，不提交二进制。版本、来源、SHA-512 与许可固定于 `codex-runtime.lock.json`。所有用户设置与任务状态留在本机用户数据目录，不写入发布包。
